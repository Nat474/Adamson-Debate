# Adamson Debate Society - Official Website

![Adamson Debate Society](assets/img/Adamson%20Debate%20Logo.jpg)

The official website for the **Adamson University Debate Society (AUDS)** - a premier student organization fostering academic discourse and intellectual excellence through the power of reasoned argumentation and dialogue.

## 🎯 About

The Adamson Debate Society is committed to nurturing holistic growth and development through:

- **Critical Thinking** - Developing analytical skills and logical reasoning through structured debates
- **Inclusive Community** - Creating a safe and welcoming environment for diverse perspectives
- **Excellence Pursuit** - Striving for the highest standards in academic achievement and competitive performance
- **Leadership Development** - Cultivating future leaders through mentorship, responsibility, and service

## 🌟 Mission & Vision

### Mission
The Adamson University Debate Society upholds core principles that guide our mission:
- Molding members in accordance to DELIVERS core values
- Valuing diversity of opinions, backgrounds, and experiences
- Upholding freedom of expression and academic freedom
- Promoting fairness and equality of opportunity
- Maintaining transparency and accountability in governance
- Building upon our legacy for future generations

### Vision
Strategic objectives for advancing debate education:
- Launch the Adamson Debate Initiative (ADI) strategic plan
- Assemble competitive teams for tournaments
- Organize intercollegiate debate tournaments and public forums
- Develop leadership skills through executive roles
- Encourage research and scholarship in debate and argumentation
- Engage with local communities to promote civic participation
- Establish partnerships with organizations and academic departments

## 📚 Programs

### Competitive Debate Training
Intensive training programs preparing members for advanced debate skills development with structured practice sessions and expert mentorship.

### Research & Analysis
Advanced research methodologies and critical analysis training to develop evidence-based arguments and strengthen analytical thinking capabilities.

### Social Advocacy
Engaging in meaningful social issues through debates and discussions, promoting civic awareness and responsible citizenship among members.

## 👥 Membership Types

### Resident Member (₱50)
- Regular member of the organization
- Access to all society activities and training
- Eligible for leadership roles and committees

### Varsity Member (Free)
- All Resident Member benefits
- Compete in off-campus tournaments
- Represent Adamson University officially
- Advanced training and coaching
- Renewed membership at start of semester

### Officer Member (By Election)
- All Varsity Member benefits
- Executive committee voting rights
- Organizational management responsibilities
- Event planning and coordination authority
- Budget and resource allocation oversight
- Mentorship of junior members

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code recommended)
- Basic knowledge of HTML/CSS/JavaScript

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/adamson-debate.git
   cd adamson-debate
   ```

2. **Open locally**
   - Simply open `index.html` in your browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000

     # Using Node.js (http-server)
     npx http-server
     ```

3. **Configure Supabase** (if using database features)
   - Create a Supabase project at https://supabase.com
   - Update `config/supabase.js` with your credentials
   - Set up database tables as needed

### Deployment

The site is configured for easy deployment on Vercel:

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy automatically with zero configuration

Alternatively, the site is static and can be deployed to:
- GitHub Pages
- Netlify
- AWS S3
- Any static hosting service
